# Tu escuela de español — 입문·초급 학습 사이트

- `index.html` : 전체 목차(레벨 필터, 진도 표시)
- `tema01/ … tema33/index.html` : 테마별 학습 페이지 (정리 + 연습문제 3세트, 총 789문항)
- `build/` : 생성 스크립트 (`python3 build.py`로 재생성)

GitHub Pages: 새 저장소 루트에 이 폴더 내용을 올리고 Pages를 켜면 `…/tema01/` 형태로 접근, 크리에이터링크에서 링크 연결.
출처: YouTube 채널 Tu escuela de español “Aprender español: nivel básico” 재생목록 (각 테마에 원본 영상 링크 포함).
